[h1]MathTheSpire (Damage Total Display)[/h1]
[h2] 1. Overview [/h2]
Tired of calculating total damage by hand? Always realize your block was not enough only after you die? Use this MOD to solve the problem!

[url=https://github.com/JMC-Mods/SlayTheSpire2_MathTheSpire] GitHub Repository [/url]
[url=https://www.bilibili.com/video/BV1ZCAxzfEuv/] Demo Video (Bilibili) [/url]

[h2] 2. Features [/h2]
[list]
    [*] Displays the total damage you are about to take this turn and the unblocked damage
    [*] Fatal damage color: used when the unblocked damage would kill the player
    [img]https://images.steamusercontent.com/ugc/16412453515860051843/860E258F25DDE14930766C724233EBBC644C7312/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
    [*] Damage warning color: used when block is insufficient but the damage is not fatal
    [img]https://images.steamusercontent.com/ugc/14602428308294953818/BA8E606A928798C8BDD278BD400DB4D8A96625CC/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
    [*] Safe block color: used when block is enough to fully block the damage
    [img]https://images.steamusercontent.com/ugc/14217793634020174051/C6177AEC02B3BD0D4CCCF1E5D73923F3838FBD89/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
    [*] Supports adjusting damage number font size, position, and colors in the in-game "Settings -> MOD Settings"
    [img]https://images.steamusercontent.com/ugc/10190707827405926106/353BD68F846F4567EFE66956D340185834F85702/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
    [*] You can change the colors to whatever you like
    [img]https://images.steamusercontent.com/ugc/16721111424746465077/FF9BE174FDD35F8195444D262240185B3D4907EA/?imw=5000&imh=5000&ima=fit&impolicy=Letterbox&imcolor=%23000000&letterbox=false[/img]
[/list]

[h2] 3. Notes [/h2]
[list]
    [*] Because of the game's mechanics, installing any MOD for the first time can cause save desynchronization. You can use [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3747533700] BetterSaveSlots [/url] to solve this
    [*] This MOD requires the following dependency:  
• [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3747526103] JmcModLib [/url]  
    [*] The localization content of this MOD (including the workshop page and changelog), except Chinese, is generated by ChatGPT. It currently supports all languages officially supported by the game. If you think any wording is inaccurate or would like to contribute your own translation, feel free to open an issue / PR on GitHub or contact me directly
[/list]

[h2] 4. Compatibility [/h2]
[list]
    [*] This mod makes extensive use of reflection and may stop working after game updates. If you find that the mod no longer works, please report it promptly.
[/list]
